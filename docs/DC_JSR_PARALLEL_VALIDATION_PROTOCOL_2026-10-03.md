# 有限 MPI 并行验证协议

用户于 2026-10-03 撤销三天内投稿期限，授权补充真正的并行验证。保留原 FEM 算子生成函数、八子域、对称加性 Schwarz、固定粗空间与 DC-JSR 的路径变差/max 规则；不开发新 PDE 或新控制分支。

## 预先固定的范围

- 单机 WSL 提供四个逻辑 CPU：正式进程数为 1、2、4，不把八进程超额订阅冒充八核扩展。
- 两个网格 N=24、32；八子域不随进程数变化，重叠一层。
- 原 Gentle 10 步、Multi-front churn 16 步；epsilon=0.08。
- Full 与 DC 使用同一分布式后端；每个配置各一次不计时完整热身，四次交替顺序的配对正式重复。
- 进程数执行顺序在网格/工况配置之间循环轮换；各 MPI 作业依次执行，不相互争用 CPU。
- 一个进程绑定一个逻辑 CPU，OMP/OpenBLAS/MKL/NumExpr 线程数均为 1。
- 全局 AIJ 矩阵、PCG 向量按连续行分布；因子 i 归属 rank=i mod P。
- 预条件子通过 VecScatter 实际交换重叠向量并反向加和；八维粗右端 Allreduce、粗因子在每个进程一致复制。局部因子独占所属进程。
- 每次求解期间冻结预条件子；成功重构后才提交清零状态。

## 计时与认证

每步开始 Barrier 后计时，各进程测量监测、局部维护、粗维护、PCG/真残差；总时间按该步进程最大值计，不累计 CPU 时间冒充墙钟。保留每进程分解，报告初始化以及初始化+序列总时间。分阶段最大值不能相加视为总时间。

算子由原函数一次串行生成，保存并哈希；分布式矩阵、覆盖行和右端预先装载。FEM 组装、输入传输与静态 scatter/模式初始化不计入维护+求解时间，单独记录。选择后的局部 PETSc 子矩阵构造与 MUMPS setup 计入维护。此测试是预装载算子序列上的维护+求解测试，不声称完整应用端到端收益。

所有正式及热身求解均独立检查 PETSc 与 NumPy CSR 真残差 <1e-8、PETSc 正收敛原因；检查因子版本、阈值集合、刷新后残余代理与粗矩阵。另以原串行后端对随机向量的预条件子作用核验初始和陈旧混合状态。进程数变化应保持相同预算序列，迭代差异如实报告。

收益不设预定成功阈值，不挑选最快重复；报告均值、样本标准差、所有配对比值、最大迭代和残差。负收益照样保留。该实验仅为单机有限强扩展，不能推断多节点可扩展性。
