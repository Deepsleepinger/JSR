# DC-JSR 交接与初步审计（2026-10-03）

当前主线为 **Defect-constrained maintenance policy based on an algebraic stale-state proxy**。保留 path 累积状态、max 残余代理约束与当前 Galerkin 粗算子同步；不加入弥散度、迟滞、冷却、Age 加权或 Krylov 反馈决策。论文 `docs/main.tex` 保持冻结。

## 已核对的实现

`benchmarks/run_dc_jsr_shadow_prototype.py` 的默认控制器使用 path / max / epsilon=0.08；实验入口还遍历 endpoint、sum 和四个 epsilon，属于消融对照。主实验比较 Full、固定 K=3 与 DC-JSR，当前没有直接运行 AB-JSR 对照。计时包含维护和求解循环，排除轨迹装配和初始局部因子构建。

每步调用 `solve_pcg_certified`，显式计算 b-Ax 的二范数，调用方断言相对真残差严格小于 1e-8。该函数在首次认证未达标时重试求解：这是求解层行为，不进入维护选择。现有打印输出没有保存逐步残差，也只展示预算序列前八项；需要补充结构化记录才能支持完整预算与认证审计。

本轮通过指定科研 Python 环境提取并执行原型控制器类，完成 200 组随机八子域实例的全部 256 子集穷举对照，验证 max 模式最小基数、刷新状态清零、闭合路径累积和归一化反例。这是控制器层验证，未重跑 FEM 耗时实验。

## 两项精确数学结论

1. 对非负 V、epsilon >= 0 和严格正维护成本，max 约束的唯一最优集合为 S={i: V_i>epsilon}。所有超限块必须刷新，其余块不必刷新；因此即使成本不等，结论也成立。排序截断实现正确，但该模式可 O(M) 扫描。若允许零成本，最优集合可能不唯一；sum 模式不继承不等成本下的结论。

2. 写 d_s=diag(A_i(s))，tau 为最近刷新时刻，并假定各范数非零。三角不等式给出

   ||d_t-d_tau|| <= sum_{s=tau+1}^t ||d_s-d_{s-1}||。

   对当前归一化端点漂移，正确关系为

   ||d_t-d_tau|| / ||d_t|| <= sum_s [||d_s||/||d_t||] [||d_s-d_{s-1}||/||d_s||] <= (max_s ||d_s||/||d_t||) V_i(t)。

   不能无条件省略范数比例因子。例如标量正对角 10→5→1，V=1+4=5，而当前归一化端点漂移为 9。若所有中间范数不超过当前范数，则端点漂移 <= V 成立。这个修正不改变算法，也不提供矩阵谱界。

闭合振荡 1→2→1 的端点漂移为零、路径状态为 1.5；不得据此宣称 Age 效应被严格消灭。

## 下一阶段验证要求

- 保存配置、轨迹、每步选择集合、决策前 V、剩余代理、真残差、迭代数和计时，以及运行环境与源码指纹。
- 原型当前在局部刷新实际完成前清零状态；正式维护实现应在成功刷新后提交重置，避免刷新失败导致状态与缓存不一致。
- 使用完整有限值检查认证，避免只依赖可被 Python 优化关闭的 assert；验证输入与 mode，禁止非法 mode 默默转入 sum。
- epsilon=0.08 是待验证容差参数，而非无参数理论常数。先冻结容差，再做留出轨迹与 epsilon 敏感性；不能把挑选容差所用轨迹称为盲测。
- 重复计时并轮换方法执行顺序，报告离散性；单次 0.952x 结果尚不足以证明稳定耗时优势。增加直接 AB 对照才能支持“超越旧控制器”的比较。
- 保持六条学术红线：代理不是谱界；端点界注明归一化条件；不宣称消灭 Age；不赋予冷却 PDE 推导；使用规范子集选择术语；看门狗仅属实现层。
