## 阶段 1：算法与贡献定型

1. 把主算法固定为 path / max / 单一 epsilon。写出初始化、感知、刷新、成功后状态提交、当前粗算子更新和认证求解的一页伪代码。明确缓存、诊断字段与参与决策的状态。
2. 将影子控制器整理为可复用实现，感知/候选选择与刷新后提交分开；补齐非法输入、非有限值、刷新失败的处理。max 模式直接选择 V_i>epsilon；不加入 Age、Cooldown、迟滞或迭代反馈。
3. 固定理论表述：严格正成本下的最优集合、带范数比例因子的对角端点界、条件性的 SPD 保持结论。明确均不推出一般矩阵谱界、迭代数界或全局耗时最优性。
4. 阅读 Svolos 原文及最接近的有状态/滞后因子维护工作，形成差异表。检查是否已有相同的累积变差触发策略；若核心已被覆盖，先调整贡献定位，再开展昂贵正式实验。
5. 列出校准、开发和留出集合。epsilon=0.08 是当前候选值；如果校准需要改变，只在预先指定校准集上进行，记录理由，并在首次查看新留出结果前冻结。保存轨迹生成规则、种子/配置、方法参数、计时边界、主要指标、全部比较方法和失败处理规则。

完成标准：维护规则可以一页说清；正式实现通过策略合同测试和小网格 FEM 审计；核心贡献与最接近工作的差异能准确说明；无需新控制分支来处理现有工况。main.tex 继续冻结。

## 阶段 2：关键算例补齐

1. 构造移动尖锐系数界面的 SPD 热扩散算子，至少覆盖低对比度、10^3 和 10^4 三档。保存实际系数范围、界面位置、网格解析度、质量项及边界条件，不以“系数参数为 10^4”代替对实际离散算例的描述。
2. 在高对比度下先验证 Full 两级基准的求解质量，区分粗空间不足与陈旧局部因子的影响。若固定粗空间已使 Full 失效，先解决并冻结共同求解器基础；所有维护方法使用同一基础，粗空间改动不能成为 DC 的隐含特权。
3. 构建可信的简化瞬态激光热模型，令上一时刻温度真正进入下一步右端，检查离散时间推进与热量收支。采用有明确出处和单位的材料/源项参数；若论文使用相变叙述，还须给出并验证相应相变模型。真实材料导热率变化与合成算子的 10^4 系数对比度分别表述。
4. 用经过认证的参考时间推进生成共同算子/右端序列，供各维护方法公平重放。重放的维护/求解收益与在线物理模拟总耗时分别记录；若声称完整模拟加速，还要实际测量包含装配和状态推进的运行。
5. 在小算例上检查空间/时间分辨率、解场及参考求解一致性，避免把物理模型或装配错误误判为维护算法问题。

完成标准：高对比度和温度时间推进均有可追溯、经过检查的算例；所有方法接收到的比较序列一致；初步验证中每次求解均满足严格真残差要求。若不具备相变或完整 SLM 的证据，就限定论文应用表述，不用名称补足证据。

## 阶段 3：正式对照与泛化

1. 主要比较至少包含 Full、固定 K=3、DC 和 AB；加入相同容差的瞬时漂移选择，作为状态记忆的对照。冻结局部因子而同步粗算子的方案用于标出复用失效边界。
2. 选定适用的物理选择对照。区分原文算法的忠实实现与 Svolos-inspired 的热问题适配；若只做适配，不称其为复现 Svolos 原算法。
3. 在单前沿、多前沿、混合转变以及高对比度代表算例上进行正式重复计时。默认至少五次；四方法位置平衡的核心比较可使用八次。固定线程与求解设置、采用平衡或预先固定的随机顺序；计时任务不并发，记录机器负载。重复次数在看结果前确定。
4. 分别考察网格 N=24/32/48 和子域数量 8/27/64。采用代表工况逐项扩展，不把所有维度做成无必要的全笛卡尔积。报告局部块大小、覆盖/重叠、粗空间及监测成本变化；串行分块验证不称为并行可扩展性。
5. 运行冻结的新留出轨迹，包含位置、访问顺序或转变时刻的改变；先完成整组运行再分析，不能用结果修改参数后继续沿用同一“留出”标签。
6. 保存每步选择、V 前后状态、迭代数、重试/失败、两种真残差、维护/求解/认证计时及源码指纹。报告均值、离散性和配对差值，对接近计时波动的优势作相应限定。

完成标准：主要主张由正式对照支撑；认证失败完整记录和解决，不能删掉失败步；有可重复净收益的代表工况，同时量化不利工况。无需每个工况都快于 Full，也不设置事后筛选的速度门槛。

## 阶段 4：机制、理论与证据冻结

1. 对照 path/endpoint、max/sum、有/无路径记忆、粗算子同步/冻结；固定其他条件，用小而有辨识力的算例解释每项建模选择。等量刷新比较可作为补充，用于区分“刷新更多”与“选择更好”。
2. 加入闭合振荡、缓慢累积、无害背景变差、非对角变化及突变重访测试。明确对角代理漏检、路径累计过度维护的可能边界；若出现失败，报告并限定适用范围。
3. 完成提前指定的 epsilon 敏感性检查，解释维护节省和迭代代价的关系；不以单次最佳点证明宽平台，也不因失败添加兜底决策规则。
4. 推导和审核能够成立的命题，区分精确数学结论、条件性结论与实验观察。最小基数直接解保持其实际复杂度，不扩写成深奥优化理论。
5. 固定主图：方法示意、逐步预算/迭代、维护与求解分项、重复计时、尺度/对比度结果、敏感性与失败边界。所有图表从原始数据生成，建立“主张—实验—数据文件”的对应清单。
6. 根据证据确认首投期刊。若强调计算力学方法与可信工程算例，按该定位组织 CMAME 版本；若最终重心是跨物理问题的数值维护方法，按该定位评估 JCP。这属于稿件定位判断，不是录用保证。

完成标准：每个主图回答一个研究问题；每条主张有相应证据；六条学术红线通过逐句审查。冻结算法、实验与主图后，解除 main.tex 冻结，进入完整重写。
