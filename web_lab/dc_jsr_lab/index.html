📖 DC-JSR 核心数学与计算复杂度原理

1. 单步对角线物理相对变化量 (O(n_i) 极速计算): v_i(t) = ||diag(A_i(t)) - diag(A_i(t-1))||_2 / ||diag(A_i(t))||_2
2. 持久缺陷记忆累加 (消灭无状态算法历史盲区): V_i^-(t) = V_i(t-1) + v_i(t)
3. 闭式最优最小基数挑选定理 (证明最小因式分解集合): S_t* = { i : V_i^-(t) > ε } (单调次模界, 全局复杂度 O(M))
4. 状态重置与出生步时间戳提交: V_i(t) = 0 (若 i ∈ S_t*), 否则 V_i^-(t); τ_i = t (若 i ∈ S_t*)
