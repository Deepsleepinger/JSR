\section{Exact Reproduction Command Reference}
To independently reproduce all tables and figures from clean checkout:
\begin{verbatim}
# 1. Clone repository at the submission freeze tag
git clone https://github.com/Deepsleepinger/JSR.git
cd JSR
git checkout v1.2-cmame-final

# 2. Run unit tests
python -m unittest discover tests/

# 3. Reproduce Flagship 48^3 (110k DOFs) benchmark
python benchmarks/run_cmame_flagship_48.py

# 4. Reproduce Subdomain Granularity Study (8 -> 27 -> 64)
python benchmarks/run_cmame_subdomain_scaling.py

# 5. Reproduce Complete Five Pillars Verification Suite
python benchmarks/run_cmame_5pillars.py --pillar all
\end{verbatim}
